1. Copiar os 2 ficheiros para a pasta "Data" do SQL Server (por exemplo: C:\Program Files\Microsoft SQL Server\MSSQL17.MSSQLSERVER\MSSQL\DATA)
2. Efectuar o Attach da base de dados seguindo os seguintes passos:
	a. Executar o Microsoft SQL Server Management Studio.  
	b. Clicar com o botão direito do rato sobre Databases e seleccionar a opção Attach.
	c. Adicionar a base de dados "MoreRhythm" através do botão de comando Add.
