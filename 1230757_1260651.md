# Trabalho Prático 1

## Objetivos

- Desenvolver arquitetura do modelo de dados
- Desenvolver modelo dimensional subjacente (com a apresentação dos atributos e respetivos tipos de
  dados para cada dimensão e tabela de factos)
- Desenvolver a estrutura de dados a criar na _Staging Area_
- Desenvolver o mapeamento de dados entre os sistemas fonte e a _Staging Area_ e entre a _Staging Area_ e o armazém de dados (para os atributos das dimensões deve ser apresentada a estratégia de _Slowly Changing Dimension (SCD)_ e eventuais operações de transformação e limpeza de dados a realizar nos diversos atributos)
